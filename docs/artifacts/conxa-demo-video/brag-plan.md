# Brag Plan: CONXA

## What is this app?
CONXA records a person doing a real software workflow once (Build Studio), compiles the recording into a self-healing, reusable skill, and lets any AI agent run it locally on the customer's machine, while the cloud dashboard shows every run.

## The angle
Problem first, product second. Every business has repeatable work spread across tools that don't talk to each other; scripts break, integrations never ship, and a live agent re-figures the job out on every run. The video draws one clean line, without knocking Claude: **operating software live** (Claude in Chrome, great for one-off tasks) vs **owning a repeatable process** (CONXA, a compiled skill that runs the same way every time). Then it shows proof across the real product, in order: Record → Compile (real Build Studio review screen) → Run locally → real Cloud dashboard.

The demo workflow is real: **"Github to Drive File Handoff"**, the workflow in the Build Studio review screen and an installed CONXA skill (`conxa-gitdrive`).

## Hook (first 2-3 seconds)
A wall of familiar business tool windows (CRM, HR, mail, payroll, drive, tickets) with a human cursor repeating the same clicks, plus a counter ticking "same task · run 214". The on-screen line: **"The work that crosses five systems is the work nobody automated."** (verbatim site copy).

## Key moments (the middle)
- **Three failed alternatives** as terminal-style cards, verbatim site copy: `Scripts / ERR selector not found`, `Integrations / 404 no API for this app`, `Guessing agents / run 41: clicked "Delete" instead of "Save"`.
- **The split:** left "AI browser agent (e.g. Claude in Chrome)": run 1, run 2, run 3, each re-exploring; right "CONXA skill": compiled once, v1.4, identical green runs.
- **Record:** Studio recording overlay over github.com → drive.google.com; step log fills live.
- **Compile:** the real Build Studio review screenshot, then the "one button, four clues" diagram (verbatim site copy), then a skill card.
- **Run locally:** a plain-words request → `execute_skill · github-to-drive-file-handoff` → steps tick on "this machine"; "Your logins never leave your machine."
- **Dashboard:** the real Operations overview (1,284 runs, 96.2% finished on their own, 41 of 43 breakages repaired themselves), a new run row sliding in.

## Outro / punchline
Three business-value lines, then the lockup:
> Show CONXA how the work is done once.
> CONXA turns it into a reusable skill that AI can execute.

## User flow worth showing
Record once in Build Studio → compile into a skill (review screen) → ask an agent in plain words → runs locally → run appears in the cloud dashboard.

## Tone
- Preset: cinematic (nearest), with polished restraint
- Creative direction: "polished startup launch film, the signal in the dark"
- Interpretation: fast cuts and confident camera moves (punch-ins on real UI), but calm type, one cyan accent, no hype adjectives, no invented superlatives.

## Audio direction
- Role: cinematic support under narration
- Music: happy-beats-business-moves-vol-1 (120.19 BPM), bed ~0.32, ducked to ~0.13 under VO, fade out over last 2s
- Music cue guidance: bundled preset read. Beat grid ≈ 0.02 + 0.5k s. Strong cue 21.01s → title reveal "Show it once." Lockup near 50.02s (on grid).
- Audio-reactive treatment: subtle; bass drives the ambient cyan glow + lockup halo. No visualizers.
- SFX posture: sparse, motion-matched (clicks for cursor actions, soft drops for list rows, one bell at the lockup).
- Restraint rule: nothing competes with the voice; no whooshes, no alarms.

## Voiceover script (Kokoro af_heart)
1. Every company runs on repetitive work, spread across tools that were never built to talk to each other.
2. Scripts break. Integrations never ship. And an agent working it out live starts from scratch, every single run.
3. Browser agents like Claude in Chrome are great for one-off tasks. CONXA is built for the work you repeat.
4. Show CONXA how the work is done, once.
5. Record the task the way your team already does it, across every app it touches.
6. CONXA compiles it into a reusable skill, with every step remembered several ways, so a redesign won't break it.
7. Now any AI agent can run it, in plain words, right on your own machine.
8. And every run reports back to the CONXA dashboard, so your team sees what ran, and what healed itself.
9. Teach a workflow once. Let AI execute it, reliably, whenever you need it.
