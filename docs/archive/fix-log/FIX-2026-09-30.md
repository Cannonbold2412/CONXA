# Fix Log — 2026-09-30

## "Do this for everyone in my spreadsheet" now works one row at a time — 2026-09-30
When someone asks their AI assistant to, say, onboard every customer in an Excel file, the assistant now knows what to do. It reads the file itself, matches each column to what the workflow needs (first name, email, and so on), and shows you that matching and the row count before starting. Then it runs the workflow once per row and tells you which rows worked and which didn't. The spreadsheet never goes to Conxa. Each workflow still does one record at a time, like a clerk handed one form at a time instead of the whole stack.

## "The page moved on" check now actually checks that the page moved on — 2026-09-30
Some steps have a check meaning "after this click, you should be on a different page". The part that builds the skill and the part that runs it understood this check in opposite ways. As a result, a click that correctly took you from a form to a thank-you page could be marked as failed. Both parts now agree: the check passes when the page address changed and fails when it didn't. Clicks that moved to a new page while recording now get this check automatically, and in the step editor it no longer asks for an address to fill in.

## Dates typed into a form now come out in the format the website expects — 2026-09-30
If you typed a date like 25/09/2026 while recording, the skill used to replay that exact text, so asking for "September 25, 2026" later confused the website. Now the skill remembers the website's date style and translates whatever date it is given into it, like a translator who knows the local way of writing dates. A date that could be read two ways is left alone rather than guessed.

## Pressing Submit no longer records the page it sends you to as a separate step — 2026-09-30
When a click sent you to a new page, the recording used to also write down "go to this exact address", including one-off numbers that would never be the same twice. Now the skill only records the click and lets the website take you where it wants to go, then quietly checks that you landed on the right kind of page. Pages you deliberately open yourself are still recorded as before.
