# Fix Log — 2026-09-23

## Added step-by-step manual test guides for the smart compiler, the AI helper, sign-in, and the Execute app — 2026-09-23
The manual testing checklist was missing instructions for four important areas: the part of the system that turns a recording into a reliable, self-healing skill; the in-editor chat helper that explains why a test run failed and suggests fixes; every place someone signs in across the whole product; and the separate desktop chat app with its live browser view. Added plain-language, click-by-click instructions for all four, written so someone without an engineering background can follow along and know exactly what "working correctly" should look like. This makes it possible for a new team member or a non-technical tester to actually run these checks themselves instead of guessing.

## Fixed a packaging checklist that would have shipped an incomplete update — 2026-09-23
Two files that power the smarter sign-in detection we shipped this week were never added to the packing list used when building the release. That meant the automatic build check caught the problem and stopped the release before it went out, rather than customers getting an update missing a piece it needed. The packing list has been corrected and the release check now passes cleanly.

## The sign-in check now remembers where it landed, and double-checks itself more carefully — 2026-09-23
Two gaps left over from the sturdier sign-in check we shipped this week. First, some apps never got told exactly which page counts as "signed in" — so every single run, Conxa would open a login window even though the sign-in from last time was still perfectly good, because it had nothing to compare against. Now it quietly remembers the first real page a sign-in lands on and uses that going forward. Second, the background double-check that asks the website "are you signed in?" used to sometimes ask over and over, tick after tick, instead of just once — like knocking on a door repeatedly instead of waiting for an answer. It now asks once, compares what the login page showed before and after, and only asks again if something new actually happens. Neither change affects how a sign-in looks to the person doing it.

## New research: which industries Conxa should sell to first — 2026-09-23
We researched 100 industries to see how much of their daily work happens in a web browser and where Conxa fits best. We found no reliable measured figures for browser time in any industry, so those percentages are clearly marked as estimates. The strongest targets are businesses that do repetitive work inside other companies' websites they can't connect to directly: medical billing offices, insurance agencies, staffing firms, freight brokers, payroll and benefits providers, and property managers. The report also lists the ten specific tasks salespeople should listen for in first calls.
