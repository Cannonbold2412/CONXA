## Wrote a free test plan for the "does it handle long, complicated tasks?" question — 2026-08-14
One of the most urgent open questions on the backlog is whether Conxa can reliably handle a long recorded task that spans several browser tabs and different websites — like pulling a file from one system and uploading it into another. Instead of just describing the risk, this adds a concrete, no-cost testing guide: five specific practice tasks on free public demo websites, each one designed to isolate a different possible failure point (switching tabs correctly, downloading and uploading files, and just plain running for a long time without stumbling). It also lists exactly what to look for while testing and where to write down what breaks, so this urgent question can actually get answered instead of staying a guess.
